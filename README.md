# Republic Kitchen - QSR Profit & Cost Reduction Campaign Landing Page

A modern, high-converting B2B campaign landing page crafted for **Republic Kitchen** to reach **Takeaway and Indian QSR (Quick Service Restaurant)** owners and cloud kitchens.

Built with **React 19**, **Vite**, **TypeScript**, **Tailwind CSS v4**, and **Lucide React**.

---

## 🎯 Campaign Purpose & Value Proposition
Indian takeaways and QSRs often struggle with:
1. **High Food & Prep Costs** (32% - 45% of top-line revenue)
2. **Chef Dependency & Poaching** (Head ustads leaving unexpectedly, inconsistent recipe quality)
3. **Heavy Wastage & Perishables** (8% - 14% spoilage on gravies, dairy, produce)
4. **Slow Turnaround During Rush Hours** (18-25 minute prep times creating delivery bottlenecks)

**Republic Kitchen** solves this by providing standardized central master base gravies (Makhani, Onion-Tomato Bhuna, Cashew Korma), vacuum-sealed marinated cuts, and standardized pantry supplies. 

The landing page features an **Interactive Savings & Profit ROI Calculator** enabling restaurant operators to input their real volume and immediately see:
- Monthly cost savings (₹)
- Annual extra net profit boost (₹)
- Net profit margin expansion (%)
- Weekly kitchen prep hours saved (hrs)
- Detailed item-level ingredient price comparisons (₹/kg)

## 🚀 Key Features & Sections

- **Impactful Hero Section**:
  - Compelling headline: *"Stop Burning 30% of Your Profit in Morning Kitchen Prep"*
  - Dual CTAs: Smooth scroll to Calculator or Request Free Tasting Box
  - Trust metrics: 180+ QSRs served, 24% avg. food cost cut, 3-minute turnaround, 99.8% taste consistency.

- **Flagship Interactive Profit & Savings Calculator**:
  - Live sliders for:
    - Cuisine type (North Indian, Biryani & Kebabs, Indo-Chinese & Rolls, Multi-Cuisine)
    - Number of Outlets / Cloud Kitchens (1 to 15+)
    - Average Daily Orders per Outlet (30 to 600+)
    - Average Order Value (AOV ₹150 to ₹900)

  - Expandable **Item-Level Cost Comparison Table** (Per Kg breakdown: In-house vs Republic Kitchen ready-to-use).

- **In-House Prep Chaos vs Republic Kitchen (Problem vs Solution)**:
  - 6 side-by-side contrast cards detailing morning prep, chef dependency, food wastage, recipe consistency, cost predictability, and peak rush turnaround.

- **Republic Kitchen Pantry Catalog**:
  - Category filters: Gravies, Marinades, Snacks, Custom Proprietary Solutions
  - Dish pairing examples, prep time saved, and shelf life indicators.
  - Custom recipe reverse-engineering under strict NDA for growing chains.

- **4-Step Frictionless Onboarding**:
  - Step 1: Free Chef Tasting Kit
  - Step 2: Custom Profit & Recipe Audit
  - Step 3: 60-Minute Kitchen Crew SOP Training
  - Step 4: Scheduled JIT Cold-Chain Supply

- **Real Founder Case Studies & Testimonials**:
  - Verified metrics from takeaway & cloud kitchen founders in Hyderabad, Delhi NCR, and Pune.

- **Interactive FAQ Accordion**:
  - Addresses core operator objections regarding taste integrity, MOQ, shelf life, and equipment requirements.

- **Lead Capture & Sample Kit Request Modal**:
  - Automatically captures the user's calculated savings and outlet count.
  - Celebratory confetti feedback and next-step delivery confirmation.

- **Sticky Bottom Conversion Bar**:
  - Appears smoothly on scroll across mobile and desktop for maximum lead generation.

## 💻 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Local Development Server
```bash
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Production Build
```bash
npm run build
```
Creates an optimized, production-ready bundle in the `dist` folder.

### 4. Preview Production Build
```bash
npm run preview
```
